# Kit de démarrage · Série Théta (θ)

## Contenu du kit

| Dossier ou fichier | Rôle |
| --- | --- |
| CLAUDE.md | Mémoire du projet, lue automatiquement par Claude Code à chaque session |
| BRIEF-CONSTRUCTION.md | Les 5 jalons de construction et leurs critères de fin |
| banque/episodes/ | Les 62 fiches d'épisodes (titre, accroche, pages, termes, références, motif) |
| charte/ | Charte graphique, règles, typographie, calendrier, bibliothèque visuelle, glossaire |
| design/canevas-gabarits/ | Les sources des gabarits validés dans Claude Design |
| design/fonts/ | Les polices Geist, Geist Mono et STIX Two Text (licence SIL Open Font) |
| tests/reference/ | Le rendu attendu de chaque gabarit, en PNG |
| conception/ | Le document de conception complet et les références, pour archive |
| calendrier.yaml, etat.yaml | Le calendrier de publication et l'état de chaque épisode |

## Démarrer

1. Décompresse le kit dans un dossier, par exemple `serie-ml`.
2. Ouvre ce dossier dans VS Code.
3. Lance Claude Code dans ce dossier et tape :

   « Lis BRIEF-CONSTRUCTION.md et réalise le jalon 1. »

4. Quand le critère de fin est atteint, passe au jalon suivant de la même façon.
